05 / 12
Deep dive

Each stage — what to say

1 · Input Validator

validators.py + models.py

  • 17 fields: type check, range, logic (Vdl ≤ Vmax, tq > 0)
  • Returns a list of human-readable errors — never throws
  • BearingInput dataclass is the typed contract

2 · Calculation Engine

engine.py + checks/

  • compute_geometry() → le, be, S, δr…
  • Runs checks 1→7 in dependency order
  • Check 2 needs A1 from geometry; Check 6 reuses Check 5's ▲

3 · Result Aggregator

BearingResult dataclass in engine.py

  • Holds all 7 check results in one object
  • overall = BEARING PASSES only if every check is OK

4 · Formatter

outputs.py + export/

  • Table, verbose, JSON for the CLI
  • PDF and CSV reports for engineers
  • Web API returns JSON via web/app.py

Live demo

Running the tool

Install & run

pip install -r requirements.txt
python main.py --sample
python main.py --web

Web UI opens at http://localhost:8000
Load sample → Run all checks → Export PDF/CSV

All available modes

  • --sample — verification case
  • --input bearing.json — your own input
  • --interactive — prompt per value
  • --batch sample_batch.csv — multiple bearings
  • --compare a.json b.json — side-by-side
  • --export-pdf report.pdf — save PDF
  • --export-csv report.csv — save CSV
  • --explain — formula reference sheet
  • --types — list bearing types
  • --web — start web UI

Honesty wins

Assumptions & future work

Assumptions made

  • Spreadsheet formulas are authoritative (not brief summary thresholds)
  • le = l − 10 mm, be = b − 10 mm (5 mm cover strip each side)
  • Eb = 2000 N/mm², σs = 290 N/mm² (hardcoded in spreadsheet)
  • Check 6: delta_total > rot_limit → OK (confirmed by sample)
  • Laminated/pot types are stubs for extensibility

With more time

  • Calibrate laminated & pot bearing thresholds
  • Deploy web UI with Docker / public URL
  • Add unit conversion helper (kN/N, mm/m)
  • More Freyssinet bearing types
  • PDF export for batch mode

Code map

Project structure — for Q&A reference

main.py            CLI entry — dispatches all modes (--sample, --web, --batch, --compare…)
validators.py      Input Validator — type, range, and logic checks for all 17 fields
models.py          BearingInput dataclass (17 parameters, typed)
engine.py          Calculation Engine — runs all 7 checks, returns BearingResult
checks/            One file per check + geometry.py
  ├─ geometry.py   le, be, tq, S, δb, δl, δr — mirrors spreadsheet cells
  ├─ check1_shear_strain.py         Eq = δr / tq  · pass: Eq < 0.7
  ├─ check2_max_design_strain.py    Et = k(Ec+Eq+Eα)  · pass: Et < 5.0
  ├─ check3_plate_thickness.py      tmin formula  · pass: tmin ≤ plate_thk
  ├─ check4_stability.py            V/A1 + Σti limits
  ├─ check5_vertical_deflection.py  ▲Total  · pass: ▲ < 0.15·ti
  ├─ check6_rotational_limit.py     ▲ vs rot_limit
  └─ check7_fixing.py               H + V/A1 permanent load
outputs.py         Formatter: table / verbose / JSON / --explain
export/            PDF (reportlab) + CSV export
web/app.py         FastAPI — thin wrapper, engine unchanged
web/static/        index.html · css/styles.css · js/app.js
bearing_types/     PAD / LAMINATED / POT registry (extensible)
tests/             50 pytest tests
.github/ci.yml     4-stage pipeline: lint → test × 4 Python versions → verify → features
