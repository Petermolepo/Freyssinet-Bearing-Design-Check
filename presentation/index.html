Deep dive

Each stage — what to say

1 · Input Validator

validators.py + models.py

  • 17 fields: type, range, logic (Vdl ≤ Vmax, tq > 0)
  • Returns list of errors — never throws
  • BearingInput dataclass = typed contract

2 · Calculation Engine

engine.py + checks/

  • compute_geometry() → le, be, S, δr…
  • Runs checks 1→7 in dependency order
  • Check 2 needs A1 from geometry; Check 6 uses Check 5 ▲

3 · Result Aggregator

BearingResult in engine.py

  • One dataclass holds all 7 check results
  • overall = PASS only if every check OK

4 · Formatter

outputs.py + export/

  • Table, verbose, JSON for CLI
  • PDF / CSV for engineers
  • Web API returns JSON via web/app.py

Assumptions & future work

Assumptions made

  • Spreadsheet formulas are authoritative (not brief summary thresholds)
  • le = l − 10 mm, be = b − 10 mm (5 mm cover each side)
  • Eb = 2000 N/mm², σs = 290 N/mm² (from spreadsheet)
  • Laminated / pot types are stubs for extensibility

With more time

  • Calibrate laminated & pot bearing types
  • Deploy web UI (Docker / cloud)
  • Unit conversion (kN/N, mm/m)
  • More bearing types from Freyssinet manual
